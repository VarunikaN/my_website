# Varunika Naini — Personal Website

Portfolio site for [Varunika Naini](https://github.com/VarunikaN) — AI & ML engineer working on sim-to-real robotics, quantization, and generative systems.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

## Deploy

Push to `main` on GitHub and connect the repo in the Vercel dashboard, or:

```bash
npx vercel --prod
```
